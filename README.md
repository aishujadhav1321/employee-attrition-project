# Employee Attrition & Performance Analytics

Machine Learning project to predict employee attrition using HR analytics data.

## Features
- Attrition Prediction
- Feature Importance Analysis
- HR Insights
- Visualization Dashboard
- High Risk Employee Detection

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Model Used
Random Forest Classifier

## Output
Predicts whether employee may leave company.
